# 광교 1남 다락방 2026

기도제목과 다락방 일정을 공유하기 위한 반응형 단일 페이지입니다.

## 배포

1. 이 폴더를 GitHub 저장소에 푸시합니다.
2. [Vercel](https://vercel.com/new)에서 해당 저장소를 Import합니다.
3. Framework Preset은 `Other`로 두고 Deploy하면 됩니다.

빌드 명령이나 환경 변수는 필요하지 않습니다.

## Windows에서 바로 열기

`다락방 기도제목 열기.exe`를 더블클릭하면 기본 브라우저로 페이지가 열립니다. 실행 파일은 `index.html`, `styles.css`와 같은 폴더에 두어야 합니다.
